# Garen assets

Stable asset folder for Garen.

Expected files:
- `overworld.png` — 144x192 PNG spritesheet (3 columns x 4 rows, 48x48 per frame)
- `battle-back.png` — 192x192 transparent PNG recommended
- `battle-front.png` — optional/future
- `portrait.png` — optional/future

Keep filenames stable so improved artwork can replace existing files without code changes.
