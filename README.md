# Ecos de Runaterra

RPG web 2D en pixel art inspirado en Pokémon GBA/NDS y League of Legends, desarrollado con Phaser + TypeScript.

## Contenido y mantenimiento

Consulta [EDITAR_CONTENIDO.md](EDITAR_CONTENIDO.md) para localizar campeones, mapas, tiles, tilesets, misiones y diálogos. La [documentación](docs/README.md) separa datos activos, planes de diseño y archivo histórico.

Bandle y los dos primeros mapas de Jonia están integrados; hay carpetas para las 21 zonas de Jonia. Yi y Wukong desbloquean sus resonancias mediante duelos. Los demás eventos de Jonia siguen pendientes. Showdown y las herramientas de pruebas se mantienen.

## Ejecutar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

GitHub Pages se publica automáticamente desde `main` mediante GitHub Actions.
